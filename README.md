# PixelCode QR — Commercial Vector QR Studio

> **"Not just pretty. Persuasive."**  
> High-converting vector QR generator with designer standees, payment frames, and barebone codes. Crafted with modern light-theme aesthetics inspired by [PixelCode.in](https://pixelcode.in).

---

## ✨ Features

- ⚡ **Dual Studio Modes**:
  - **Basic Mode**: Streamlined for instant link-to-code creation without distractions.
  - **Advanced Mode**: Full vector dot styling (circles, squircle, rounded, diamond), eye corner control, logo branding, and custom standee typography.
- 🎨 **10 Designer Standee Templates**:
  - **Barebone QR**: Pure, clean raw vector QR code with zero frames or bloat.
  - **Classic "SCAN ME"**: High-converting banner pill with camera badge.
  - **UPI / Pay Standee**: Counter standee for Google Pay, PhonePe, Paytm, and BHIM UPI.
  - **Dining Menu**: Table tent frame tailored for cafes and digital menus.
  - **WhatsApp Direct**: Verified-style WhatsApp chat trigger.
  - **Google Review**: 5-star rating standee for local business checkout counters.
  - **Wi-Fi Auto-Connect**: One-scan guest network connect.
  - **Executive vCard**: Modern digital business card format.
  - **Event & Ticket**: VIP badge standee for summits, check-ins, and conferences.
  - **App Store / Play Store**: Multi-store download badge for apps.
- 📱 **100% Mobile-Friendly Experience**:
  - Floating live preview Picture-in-Picture (PiP) dock on small screens.
  - Smart viewport observer automatically reveals the live preview as you customize content and styling.
  - Optimized touch targets, iOS zoom prevention (16px form inputs), and zero layout shifts.
- 🚀 **Vector & Print-Ready Exports**:
  - **High-Res PNG**: Crystal-clear 2048px raster file for web & social media.
  - **Vector SVG**: Infinitely scalable vector for billboards, signage, and merchandise.
  - **Print-Ready PDF**: Vector PDF with embedded typography ready for professional printing.
- 💼 **Integrated PixelCode Agency Promotion**:
  - Direct WhatsApp trigger for custom web design, mobile apps, and enterprise software inquiries.

---

## 🛠️ Tech Stack

- **HTML5 & CSS3**: Vanilla CSS with glassmorphism, fluid typography, responsive CSS grid, and PixelCode brand design tokens.
- **JavaScript**: Pure client-side canvas engine with `qr-code-styling` and `jspdf`.
- **Zero External Backend**: Fast, private, and runs completely locally or on any static hosting (Vercel, GitHub Pages, Netlify).

---

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/VishnuWD/pixelcode-qr.git

# Navigate into the project
cd pixelcode-qr

# Run with any static HTTP server (e.g. npx serve)
npx serve .
```

Then open `http://localhost:3000` in your browser.
